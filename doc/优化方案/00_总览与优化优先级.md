## 0.2 项目独特价值定位

在 `z-biz-tool` 工具矩阵中，本项目的差异化不在"又一个笔记编辑器"（那是 `z-biz-tool-note` 的领域），而在于：

1. **本地优先的私有 RAG 问答**：文档切片、索引、检索全部在本地完成（`src-tauri/src/rag.rs`），仅生成回答一步调用用户自配的 OpenAI 兼容 API。知识不出本机（除 LLM 调用外），这是相对云端知识库产品的核心卖点。
2. **答案可溯源**：`ask_question` 已返回 `Citation { doc_id, doc_name, chunk_index, text, score }`（`src-tauri/src/commands.rs` L102-L117），前端已有引用卡片展开查看（`src/components/ChatPanel.tsx` L100-L156）。**来源可追溯是本产品的第一性原则**，后续一切优化不得削弱它。
3. **零运维桌面形态**：Tauri 2 单二进制 + 文件系统存储，无服务端依赖，适合个人/小团队离线知识资产沉淀。

因此优化的主线是：**把"能跑通的 RAG demo"升级为"可信、可解释、可撤销、可成长的个人知识引擎"**，而不是引入无关能力（不做协同编辑、不做多租户、不做发布系统）。

## 0.3 现状一句话结论

基于源码静态阅读：当前实现是一个**结构清晰但深度不足的 MVP**——文档上传→字符切片→JSON 落盘→2-gram 关键词检索→LLM 生成→引用展示的主链路完整可跑；但文本提取（PDF/Word）基本失效、检索无任何索引结构、无知识组织（分类/标签/链接）、无历史持久化、无删除确认、API Key 明文、`delete_document` 存在路径穿越、`src/agent/` 是未接线的 SQL Agent 桩代码。详见 [01 文档](./01_现状审计与问题清单.md)。

## 0.5 分阶段能力概览

完整任务拆解见 [05 文档](./05_实施路线与任务拆解.md)，此处为能力视角的五阶段摘要：

```
阶段一（止血）    安全修复 + 删除确认/回收站 + 文本提取修复 + 容错
阶段二（地基）    SQLite 存储引擎 + FTS5 全文索引 + schema 版本化 + 数据迁移
阶段三（检索）    BM25/中文分词升级 + 引用定位增强 + 检索质量评测集 + 召回可解释
阶段四（组织）    标签/分类/双向链接 + 对话历史持久化 + 批量导入 + 导出/备份
阶段五（智能）    向量语义检索（混合召回） + 知识图谱视图 + Agent 辅助问答（只读边界）
```

阶段二的存储引擎选型（SQLite + FTS5，向量能力延后到阶段五按评测结果决策）是**首要技术决策**，理由与权衡见 [03 文档 §3.1](./03_技术架构与性能优化.md)。

## 0.6 核心原则（全方案约束）

后续所有设计必须同时满足四条不可妥协原则，验收时逐条对照：

1. **知识来源可追溯**：每条知识/每个引用能定位到来源文档与位置；原文入库留存。
2. **检索结果可解释**：召回结果附带可理解的匹配依据（命中词/分数构成），不做黑盒排序。
3. **危险操作可撤销**：删除/覆盖/批量导入均有确认与恢复路径（回收站、备份、事务）。
4. **Agent 不自动篡改知识**：任何 LLM/Agent 产出只能以"建议"形态进入待确认区，写知识库必须经用户显式确认，Agent 无直接写权限。

## 0.7 量化验收目标（拟定，非实测）

完整矩阵见 [06 文档](./06_测试验收与风险清单.md)，此处列关键项。所有数值为**验收目标**，测试环境假设：Apple Silicon Mac、本地 SSD、100 篇文档 / 约 5,000 切片规模的知识库、100 条人工标注评测查询。

| 指标 | 目标 | 假设/口径 |
| --- | --- | --- |
| 检索 Recall@5 | ≥ 0.80 | 100 条标注查询，相关切片人工判定 |
| 检索 Precision@5 | ≥ 0.60 | 同上评测集 |
| MRR@10 | ≥ 0.65 | 同上评测集 |
| 检索 P95 延迟 | ≤ 200ms | 5,000 切片规模，不含 LLM 调用 |
| 首 token 延迟（流式） | ≤ 2s | 本地网络至 LLM 网关正常时 |
| 100 篇文档批量导入 | ≤ 5min 且 UI 不冻结 | 平均 200KB/篇混合类型 |
| 删除误操作恢复率 | 100% | 回收站 30 天窗口内 |
| 崩溃后数据完整性 | 0 损坏 | kill -9 注入 50 次，SQLite 事务保证 |
| 重复文档检出率 | 100% | 内容 SHA-256 精确去重 |
| PDF 文本提取可用率 | ≥ 90% | 20 个真实世界 PDF 样本，人工判定可读 |
