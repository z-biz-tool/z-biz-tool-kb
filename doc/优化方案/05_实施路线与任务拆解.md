## 5.6 全局兼容与回滚策略

1. **版本策略**：阶段一 = 0.2.x patch 流；阶段二起 0.3.0（存储格式变更，minor 升格并在 README 标注）；每阶段独立 tag，可整阶段 revert；
2. **数据兼容矩阵**：新代码必须能读上一版数据（JSON→SQLite 有迁移器）；降级路径 = migrate-back 导出 + 旧版本二进制（保留一个版本窗口）；
3. **IPC 契约**：只增不改不删原则；删除字段需隔一个 minor 版本并先标 deprecated；
4. **feature 开关**：检索策略、向量、备份频率均入 settings 表，出问题运行时可关，不必回滚二进制；
5. **发布前检查**：迁移器在 CI 用固定旧格式 fixture 跑通（含损坏文件 fixture）；release.sh 修复后首次发布走 --dry-run 复核。
